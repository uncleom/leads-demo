# Карта leads-demo

Читать вместо сканирования кода.

## Файлы

| Файл | Что |
|---|---|
| `app.py` | всё приложение: FastAPI, механический слой, вызов модели, selftest. Один файл |
| `static/index.html` | страница целиком: разметка, стили Ledger, логика. Без сборки. Схема воркфлоу вставлена в HTML, потому что сервер отдаёт только этот файл |
| `data/business.json` | профиль Bayline Comfort Co. и дефолтные пороги (зона, услуги, минимум, часы, уверенность) |
| `data/requests.json` | 40 синтетических заявок из form / WhatsApp / Instagram |
| `data/judgments.json` | записанный прогон модели по всем 40 заявкам. Кнопка на странице его читает, модель не зовёт |
| `workflow/diagram.svg` | экспорт n8n-воркфлоу. Источник правды; копия живёт внутри `static/index.html` |
| `workflow/lead-qualification.json` | сам воркфлоу n8n |
| `Dockerfile` | python:3.12-slim, uvicorn. Механика считается на запросе, мнения модели лежат в образе |

## Как устроен прогон

Одна пачка заявок, дешёвые правила, модель только на выживших.

1. **Механика** (бесплатно, детерминированно, на каждом нажатии). Первое сработавшее правило снимает заявку: спам → нет предмета → дубль за сутки → вне зоны → не наша услуга → ниже минимума → выезд вне смены без доплаты.
2. **Исходы.** Снятые правилами идут в вежливый отказ с именем правила и цитатой. Выжившие получают записанное мнение модели: к менеджеру · ссылка на календарь · в рассылку · отказ · либо корзина «спорные» (низкая уверенность или цитата не из текста).
3. **Сравнение цены.** В ответе `/run` считаются оба usage: если бы модель смотрела все 40, и если смотрит только выживших. Живого вызова на странице нет.
4. Прейскурант настоящий, цифры - с записанного прогона (`./app.py --record`).

## Что видит посетитель

Светлая страница Ledger (бумага `#f7f5f0`, сталь `#1f3a5f`, Inter + IBM Plex Mono только на цифрах, времени и именах правил). За десять секунд: крупная цифра «человек читает N из 40», пороги правятся на странице, исходы по корзинам, потом сводка снятых по правилам (клик раскрывает карточки; у карточки - имя правила и цитата), схема n8n вписана в ширину колонки. Стоимость модели - мелкая строка внизу. Дата записи на странице, кнопка модель не зовёт. Контактов на странице нет.

## Решения, за которыми стоит причина

- **Правила узнаваемые владельцу сервиса.** Вне зоны, не наша услуга, дубль, спам, сумма ниже минимума, ночной выезд без доплаты - то, что диспетчер отсекает руками за секунду.
- **Цитата - подстрока документа.** Если модель сослалась на фразу, которой в заявке нет, решение становится спорным и уходит человеку. Иначе «объяснение» - декорация.
- **Пороги правятся на странице.** Зона, минимум, часы, порог уверенности - параметры; следующий прогон механики идёт по новым значениям, дефолт живёт в `business.json`.
- **Витрина светлая и деловая.** Соседние демки тёмные и моноширинные; эта не должна на них походить.

## Данные

Синтетика. Компания Bayline Comfort Co. и город Port Meridian вымышлены. Имена, телефоны `+1-555-…`, почты на `example.com`. Живых людей в корпусе нет.
