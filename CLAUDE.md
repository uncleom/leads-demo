# leads-demo — витрина «квалификация входящих заявок»

**Что это:** демо-страница для портфолио. Одна пачка входящих заявок сервисной компании (установка и обслуживание кондиционеров, мелкий ремонт) разбирается дешёвыми правилами, после которых модель смотрит только выживших и раскладывает по исходам.

**Стек:** Python, FastAPI, один `app.py`, статика без сборки. Модель: Vertex trial, фолбэк `GEMINI_API_KEY_FREE`. OpenRouter не используется.

**Прод:** https://demo-leads.om-dev.uk. Локально `./app.py` на :8080.

## Команды

```bash
./app.py                 # локально на :8080 (uv поднимет окружение сам)
./app.py --selftest      # механика и сборка, без вызова модели
./app.py --record        # записать мнения модели; страница сама модель не зовёт
```

Деплой: push в `main` → Coolify, как у rag-demo. Не пушить, пока не попросили.

## Правила проекта

- Заявки только синтетические. Живых людей в корпус не заносить.
- Сравнение цены честное: usage считается и «модель на всех», и «модель на выживших». Разница только в воронке.
- Цена на странице - настоящая, прейскурант в `app.py`.
- `./app.py --selftest` не имеет права звать модель. Если зовёт - это баг.
